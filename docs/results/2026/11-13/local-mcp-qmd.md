## Limits

This is keyword retrieval through an authored legacy stdio client. It does not
accept embeddings, reranking models, registered native/GUI clients, hosted
Auth/API/MCP/OAuth, sync, writes, personal files or full vAFS. Existing Inspector
I01 and CLI Q01 results retain their own sources. External QMD configuration can
still change after startup; current eligible files remain authoritative. Process
snapshots and owned-cache absence are not whole-host, every-child or network
attestation. The first failed attempt has no recovered JSON or teardown proof.
Local Storage Guard failed, so no local install/build/test/index/server ran.
